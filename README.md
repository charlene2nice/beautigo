# BeautiGo Prototype

BeautiGo is a static HTML/CSS/JavaScript prototype for a beauty and grooming marketplace.

## Included
- Home
- Explore / provider discovery
- Provider profile
- Booking
- Booking confirmation
- Login + signup
- Customer dashboard
- Professional dashboard

## Demo authentication
Signup/login is simulated with browser localStorage. No real passwords, payments, database, messaging backend or image upload service is connected yet.

## Run locally
Open `index.html` in a browser. For best results, use a simple local server or deploy the folder to Netlify.

## Professional dashboard
The professional dashboard demonstrates bookings, services, portfolio, reviews, messages and profile management interactions. Some editing/upload actions are UI placeholders for a future backend.
